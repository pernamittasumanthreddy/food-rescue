# FoodRescue — Enterprise Surplus Food Rescue & Donation Platform

> **"Save Food • Feed People • Build a Sustainable Future"**

FoodRescue is an Indian national-scale enterprise surplus-food rescue and donation web application. It connects surplus food generators (restaurants, hotels, supermarkets, caterers, households, corporate cafeterias) with recipients (NGOs, shelters, community kitchens, verified beneficiaries), powered by **FSSAI Food Safety Verification**, an **AI Matching Engine**, dynamic **Logistics & Volunteer Dispatch**, and real-time **ESG Carbon Footprint & Impact Analytics**.

---

## Key Features & Highlights

- **Aesthetic Direction**: Strictly **no blue** primary design. Tailored in an Indian eco-social enterprise palette:
  - **Forest Green** (`#126B4F`), **Emerald Green** (`#2E8B57`), **Warm Orange** (`#F28C28`), **Saffron** (`#F4A340`), **Terracotta** (`#C65D3A`), **Warm Cream** (`#FFF8EC`).
- **12+ Role-Based Authenticated Dashboards**:
  1. Super Admin Dashboard
  2. Regional & District Admin Dashboard
  3. Food Donor Dashboard
  4. Restaurant Surplus Dashboard
  5. Hotel & Banquet Dashboard
  6. NGO / Food Bank Dashboard
  7. Volunteer Rescue Dashboard
  8. Delivery Partner / Driver Dashboard
  9. Beneficiary & Shelter Dashboard
  10. Corporate CSR & ESG Dashboard
  11. Government Food Security Authority Dashboard
  12. Analytics & Predictive Impact Dashboard
  13. Food Safety Inspector Dashboard
- **End-to-End Workflow**:
  $$\text{Donor Creation} \rightarrow \text{FSSAI Inspection} \rightarrow \text{AI Smart Matching} \rightarrow \text{Allocation} \rightarrow \text{Volunteer/Fleet Pickup} \rightarrow \text{Distribution} \rightarrow \text{Beneficiary Verification} \rightarrow \text{ESG Analytics}$$
- **Authentic Indian Context**:
  - Currency in Indian Rupee (**₹**)
  - Indian phone formatting (**+91**)
  - Indian states, districts, and cities (Vijayawada, Guntur, Visakhapatnam, Hyderabad, Bengaluru, Chennai, Mumbai, Pune, Delhi, etc.)
  - FSSAI food safety regulations, NGO Darpan IDs, 80G tax exemption certificates, and CSR Schedule VII reporting.
- **Multilingual Support (i18n)**:
  - English (`en`)
  - Telugu (`te` - తెలుగు)
  - Hindi (`hi` - हिन्दी)
- **Zero API Dependencies**:
  - Runs 100% client-side in the browser with full state persistence, instant 1-click persona switching, and interactive rescue simulation.

## Quick Start (Local Development)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Web Application
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.
